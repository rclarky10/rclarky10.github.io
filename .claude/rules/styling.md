# Styling

All custom CSS overrides go in `styles.css`. The site uses UNL branding:

- **Scarlet**: `#D00000` (link color, primary headings)
- **Cream**: `#F5E6D0`
- Theme base: Bootstrap "cosmo" + Quarto "brand"
- Custom utility classes: `.btn-unl`, `.text-unl-scarlet`, `.text-ku-blue`

Profile image uses a 3:4 aspect ratio with `border-radius: 10px`.
